# SmartBudgetManagger
Part 1: Audience Profile (Audience Analysis)
Q: Who will use the workbook?
Answer: Regular users, students, and employees who need a simple personal tracking system to manage
their financial status, income, and daily expenses.
Q: What is their expected level of Excel knowledge?
Answer: Beginner to intermediate level. They know basic skills such as opening files, loading spreadsheets,
entering data, and basic web browsing.
Q: What tasks do they need to perform?
Answer: They need to record monthly income, enter daily expenses under specific categories, track spending
across categories, and review the overall monthly balance.
Q: What terms may be difficult for them?
Answer: Excel interface concepts and terminology such as Formulas (SUM, SUMIF), Conditional Formatting,
Data Validation, Worksheets, and Page Layout.
Q: What problems might they encounter?
Answer: Misunderstanding Excel functions or formulas, reading/interpreting financial totals incorrectly, or
accidentally modifying formulas in calculated cells.
Q: Will they read the documentation carefully or scan it quickly while working?
Answer: They will scan it quickly while working, as regular users typically consult the user guide only when
they encounter a specific difficulty or technical issue.

Part 2: Required Deliverables
1. Requirements Document Structure
(Software_Requirements_SmartBudget_BENABERKANE_Group11.docx)
 1. Document Purpose: Specifies user and system requirements for SmartBudget Manager to facilitate
clear utility and ease of use.
 2. Product Overview: A lightweight Excel tool that helps users track financial status, manage income and
expenses, and view visual summaries.
 3. Target Users: Students, employees, and regular users needing a straightforward tracking system for
personal finances.
 4. Functional Requirements: Record income/expenses in Transactions sheet, categorize expenses
automatically, calculate monthly balance using SUM/SUMIF formulas, display pie/column charts, and
trigger budget overspending alerts.
 5. Non-Functional Requirements: User-friendly interface, fast formula recalculation, clear visual layout,
and compatibility across standard Excel versions.
 6. Assumptions and Limitations: Assumes the user has Microsoft Excel or a compatible worksheet viewer
installed. Limitations include manual data entry (no automated bank feed synchronization).
2. README File Outline (README_BENABERKANE_Group11.docx)
 What the software does: Helps users easily track personal financial status, organize expenses by
categories, and monitor monthly balance.
 What is needed to use it: Microsoft Excel (2016, 2019, 2021, Microsoft 365) or any fully compatible
worksheet reader.
 How to get started: Open SmartBudget_Manager.xlsx, navigate to the Transactions worksheet, enter
your initial income and expense entries, select categories, and view the Dashboard worksheet to monitor
your budget.
3. User Guide Structure &amp; Outline (SmartBudget_User_Guide_BENABERKANE_Group11.docx)
 Cover Page: Includes Author Name (BENABERKANE MOHAMED AMINE, Group 11) and Software Title
(SmartBudget Manager).
 Table of Contents: Organized into 10 key sections: 1. Introduction, 2. Before you begin, 3. Open the
workbook, 4. Enter income, 5. Add an expense, 6. Select an expense category, 7. Set a monthly budget
limit, 8. Read the dashboard, 9. Save and protect your file, 10. Contact and support.
 1. Introduction: Welcome to SmartBudget Manager, designed to help you keep your money organized
efficiently.
 2. Before You Begin: Ensure Microsoft Excel or a compatible spreadsheet program is installed on your
computer.
 3. Open the Workbook: Double-click SmartBudget_Manager.xlsx to launch the application.
 4. Enter Income: Navigate to the Transactions worksheet and record incoming funds in the Income
column.

 5. Add an Expense: Select the first empty row in the Transactions table, enter the date, type a
description (e.g., Electricity bill), choose a category, enter the amount in the Expense column, and press
Enter.
 6. Select an Expense Category: Choose predefined categories (Food, Transport, Rent, Health, Education)
from the Category drop-down list.
 7. Set a Monthly Budget Limit: Define monthly spending thresholds on the Dashboard to activate visual
overspending warnings.
 8. Read the Dashboard: Review total income, total expenses, net balance, category pie/column chart,
and conditional formatting alerts.
 9. Save and Protect Your File: Save changes regularly (Ctrl + S) and optionally set sheet protection to
prevent formula modifications.
 10. Contact and Support: If you get stuck or face difficulties, contact technical support at
ma.benaberkane@esi-sba.dz.
